# Logistics & Delivery Performance Analytics

## Project Overview
This project uses Microsoft Power BI to analyze e-commerce orders, revenue, shipments, delivery statuses, and shipping partner performance.

## Objectives
- Analyze total orders and revenue.
- Monitor shipment and delivery status.
- Compare shipment counts across shipping partners.
- Understand monthly order trends.
- Present logistics data through interactive dashboards.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset
- GitHub

## Dashboards

### 1. Logistics Overview
This dashboard presents:
- Total Orders
- Total Revenue
- Total Shipments
- Total Customers
- Shipment Count by Shipping Partner
- Monthly Order Trend
- Order Year Filter

### 2. Delivery Performance
This dashboard presents:
- Total Shipments
- Pending Shipments
- Delivered Shipments
- Delivery Status Distribution
- Shipment Count by Shipping Partner
- Shipment Details Table

## Dataset Description
The project uses three data tables:
- **Orders:** order ID, customer ID, order date, total price, and coupon information.
- **Shipments:** shipment ID, order ID, shipment date, delivery status, and shipping partner.
- **Customers:** customer ID and available customer attributes, including loyalty points.

## Project Report
The detailed project report is available in `Logistics_Delivery_Performance_Project_Report.docx`.

## How to Use
1. Download the Power BI `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. If required, reconnect the source dataset files.
4. Explore both dashboard pages and their filters.

## Conclusion
This project demonstrates how Power BI can transform logistics and order data into interactive visual reports that support business analysis.
